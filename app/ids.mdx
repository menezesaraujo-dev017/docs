Na Sync Apps, cada recurso da plataforma recebe um identificador unico no formato hexadecimal de 24 caracteres. Esse padrao garante que bots, lojas, sorteios, tickets e outros itens possam ser localizados com precisao no sistema, sem conflitos ou ambiguidades.

Um exemplo de ID e `6a7504d0828228c7b19af029`. Voce encontrara esse tipo de identificador em praticamente todas as secoes do painel.

## Onde encontrar cada ID

| Recurso | Onde encontrar o ID |
| --- | --- |
| Bot | Pagina de detalhes do bot no painel |
| Loja | Secao Lojas no painel |
| Sorteio | Secao Sorteios no painel |
| Ticket | Secao Tickets no painel |
| Pagamento/Backup | Secao de Pagamentos no painel |

<Tip>
  Sempre informe o ID do recurso ao abrir um ticket de suporte. Isso ajuda a equipe a localizar rapidamente o item em questao e agilizar o atendimento.
</Tip>

<AccordionGroup>
  <Accordion title="Por que cada recurso tem um ID unico?">
    Os IDs unicos existem para garantir a localizacao precisa de cada item dentro do sistema. Como varios usuarios criam bots, sorteios e tickets simultaneamente, o identificador impede confusao entre recursos com nomes parecidos ou duplicados. Ele tambem e usado internamente para vincular acoes, pagamentos e registros de seguranca ao recurso correto.
  </Accordion>
</AccordionGroup>
