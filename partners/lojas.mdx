Lojas virtuais e plataformas de e-commerce sao os pontos de contato direto entre comerciantes e consumidores. Ao integrar sua plataforma a Sync Apps, voce oferece aos seus usuarios a capacidade de receber pagamentos via PIX de forma nativa, sem redirecionamentos para gateways externos, com confirmacao automatica em ate 5 segundos apos o pagamento. Isso significa menos abandono de carrinho, maior conversao e uma experiencia de checkout fluida para o consumidor final. Seja voce um plugin de WooCommerce, uma plataforma SaaS de e-commerce ou um sistema customizado, a integracao e simples e bem documentada.

## Plataformas Compativeis

A Sync Apps aceita inscricoes de parceiros que operam sobre diferentes tecnologias e stacks de e-commerce. As plataformas mais comuns incluem:

- **WordPress/WooCommerce**: plugins que adicionam PIX como metodo de pagamento no checkout do WooCommerce, com geracao automatica de QR Code e atualizacao de status do pedido
- **OpenCart**: extensoes de pagamento que integram o modulo de PIX no fluxo de finalizacao de compra, suportando multiplas moedas e idiomas
- **Magento/Adobe Commerce**: modulos enterprise-ready com suporte a multi-store, split de pagamentos e integracao com o sistema de pedidos nativo
- **Plataformas custom/SaaS**: sistemas proprietarios de e-commerce, marketplaces ou ferramentas de vendas online construidas do zero, desde que possuam capacidade de fazer chamadas HTTPS a APIs externas
- **Shopify, Nuvem Shop e outras plataformas hosted**: integracoes via app ou webhook para lojistas que usam plataformas fechadas mas precisam de PIX nativo

## Beneficios Exclusivos

Parceiros da categoria Lojas Virtuais desfrutam de beneficios pensados especificamente para acelerar a adocao do PIX entre comerciantes online:

- **Checkout sem redirecionamento**: o QR Code e gerado e exibido diretamente na pagina de pagamento da loja, sem levar o cliente para fora do ambiente
- **Confirmacao em ate 5 segundos**: assim que o pagamento e confirmado, o webhook atualiza o status do pedido automaticamente
- **QR Code e copia e cola**: suporte a ambos os metodos de pagamento PIX, atendendo usuarios de todos os bancos e apps
- **Personalizacao do QR Code**: opcao de customizar a aparencia do QR Code com a identidade visual da loja (logotipo, cores)
- **Dashboard de conversao**: acesso a metricas de taxa de conversao de PIX vs outros metodos de pagamento para otimizar o checkout
- **Notificacoes automaticas**: o comerciante e notificado por e-mail ou webhook quando um pagamento PIX e confirmado, agilizando a separacao do pedido

## Requisitos

Para se qualificar como parceiro loja virtual, sua plataforma deve atender aos seguintes criterios:

- **Capacidade de integracao via API**: sua plataforma deve conseguir fazer requisicoes HTTPS para `https://api.syncpay.com.br` e processar respostas JSON
- **Webhook endpoint**: voce precisa expor um endpoint HTTPS publico para receber notificacoes de mudanca de status de pagamento
- **Suporte a HTTPS/TLS 1.2**: todas as comunicacoes entre sua plataforma e a Sync Apps devem usar criptografia moderna
- **Documentacao ou plugin publico**: para plataformas open-source, e recomendado ter um plugin ou extensao documentada. Para SaaS, uma pagina de ajuda explicando a integracao e suficiente
- **Experiencia com comerciantes**: sua plataforma deve ter usuarios ativos (comerciantes) que se beneficiarao da adicao do PIX

## Fluxo de Integracao

A integracao de uma loja virtual com a Sync Apps segue tres passos principais:

<Steps>
  <Step title="Instalar e configurar">
    O comerciante instala o plugin, extensao ou ativa a integracao no painel da plataforma. Durante a configuracao, ele insere a API Key da Sync Apps e define o endpoint de webhook.
  </Step>
  <Step title="Gerar cobranca no checkout">
    Quando o cliente escolhe PIX como metodo de pagamento, a plataforma chama a API da Sync Apps para criar uma cobranca com o valor do pedido. O QR Code e exibido na tela de confirmacao.
  </Step>
  <Step title="Confirmar e atualizar pedido">
    Apos o pagamento, a Sync Apps envia um webhook para a plataforma. O status do pedido muda automaticamente para "pago" e o comerciante e notificado para iniciar o envio.
  </Step>
</Steps>

## Exemplo de Integracao no Checkout

Veja como criar um pagamento PIX a partir do checkout de uma loja virtual:

<CodeGroup>

```bash curl
# Criar cobranca PIX para um pedido de R$ 150,00
curl -X POST https://api.syncpay.com.br/v1/payments \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sua_api_key" \
  -d '{
    "amount": 15000,
    "currency": "BRL",
    "description": "Pedido #9876 - Loja Exemplo",
    "expires_in": 1800,
    "order_id": "order_9876",
    "customer": {
      "name": "Maria Oliveira",
      "email": "maria@email.com",
      "tax_id": "123.456.789-00"
    },
    "callback_url": "https://sualoja.com.br/webhooks/syncpay"
  }'
```

```javascript JavaScript (Node.js)
const payment = await fetch('https://api.syncpay.com.br/v1/payments', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer sua_api_key'
  },
  body: JSON.stringify({
    amount: 15000,
    currency: 'BRL',
    description: 'Pedido #9876 - Loja Exemplo',
    expires_in: 1800,
    order_id: 'order_9876',
    customer: {
      name: 'Maria Oliveira',
      email: 'maria@email.com',
      tax_id: '123.456.789-00'
    },
    callback_url: 'https://sualoja.com.br/webhooks/syncpay'
  })
}).then(r => r.json());

// Exibir QR Code no checkout
const qrImage = document.createElement('img');
qrImage.src = payment.qr_code;
document.getElementById('pix-container').appendChild(qrImage);

// Exibir copia e cola
const copyPaste = document.getElementById('pix-copy-paste');
copyPaste.value = payment.pix_copy_paste;
```

</CodeGroup>
