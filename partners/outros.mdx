A categoria **Outros** do Programa de Parceiros Sync Apps foi criada para abrigar todo tipo de plataforma que nao se encaixa estritamente em gateways de pagamento ou lojas virtuais tradicionais. Aqui entram infoprodutos, ferramentas de automacao, CRMs, ERPs, bots de WhatsApp e Telegram, sistemas de gestao, plataformas de membrosia, software de cobranca recorrente e qualquer outro servico que precise processar pagamentos PIX de forma programatica. Se voce tem uma ferramenta que ajuda pessoas ou empresas a vender, cobrar ou gerenciar receitas, essa e a porta de entrada para integrar a Sync Apps e oferecer PIX nativo aos seus usuarios.

## Como Funciona a Integracao

A integracao para servicos da categoria Outros segue um fluxo padronizado, adaptavel a diferentes arquiteturas e casos de uso:

<Steps>
  <Step title="Configurar credenciais">
    O usuario da sua plataforma insere a API Key da Sync Apps no painel de configuracoes do seu servico. Voce armazena essa chave de forma segura (criptografada) para usar em todas as chamadas a API.
  </Step>
  <Step title="Criar cobranca via API">
    Quando um pagamento e necessario, sua plataforma chama `POST /v1/payments` com o valor, descricao, dados do pagador e o endpoint de webhook. A Sync Apps retorna o QR Code e o copia e cola.
  </Step>
  <Step title="Apresentar ao pagador">
    Sua interface exibe o QR Code (imagem base64) ou o codigo PIX para copia. O pagador usa o app do banco para confirmar a transacao.
  </Step>
  <Step title="Processar webhook e executar acao">
    Ao receber o webhook `payment.confirmed`, sua plataforma executa a acao configurada: libera acesso a um curso, ativa uma assinatura, atualiza o status no CRM, dispara um e-mail de boas-vindas ou qualquer outro comportamento customizado.
  </Step>
</Steps>

## Fluxo Completo de Exemplo

Vamos ilustrar o fluxo completo para uma **plataforma de infoprodutos** que vende cursos online. O objetivo e cobrar via PIX e liberar o acesso automaticamente assim que o pagamento for confirmado:

<Steps>
  <Step title="Aluno clica em comprar">
    No site da plataforma, o aluno escolhe o curso e clica em "Comprar com PIX". A plataforma captura os dados do aluno (nome, e-mail, CPF) e o valor do curso.
  </Step>
  <Step title="Plataforma gera QR Code">
    A plataforma chama a API da Sync Apps e cria uma cobranca de R\$ 197,00. O retorno inclui o QR Code e o copia e cola. A plataforma exibe ambos na tela de checkout.
  </Step>
  <Step title="Aluno paga no app do banco">
    O aluno escaneia o QR Code ou cola o codigo PIX no app do banco. A transacao e processada pela rede bancaria em segundos.
  </Step>
  <Step title="Sync Apps envia webhook">
    A Sync Apps detecta a confirmacao do pagamento e dispara um webhook `payment.confirmed` para o endpoint configurado pela plataforma.
  </Step>
  <Step title="Plataforma libera acesso">
    Ao receber o webhook, a plataforma: (1) marca o pedido como pago no banco de dados, (2) cria a conta do aluno no sistema de LMS, (3) envia um e-mail de boas-vindas com link de acesso ao curso.
  </Step>
</Steps>

## Codigo de Exemplo

Aqui esta um exemplo completo de integracao usando Python, desde a criacao da cobranca ate o processamento do webhook:

<CodeGroup>

```python Python (Flask)
from flask import Flask, request, jsonify
import requests
import os

app = Flask(__name__)
SYNC_API_KEY = os.environ.get('SYNC_API_KEY')
SYNC_BASE_URL = 'https://api.syncpay.com.br'

def create_pix_payment(amount_cents, description, customer, callback_url, metadata):
    """Cria uma cobranca PIX na Sync Apps."""
    payload = {
        'amount': amount_cents,
        'currency': 'BRL',
        'description': description,
        'expires_in': 3600,
        'customer': customer,
        'callback_url': callback_url,
        'metadata': metadata
    }
    
    response = requests.post(
        f'{SYNC_BASE_URL}/v1/payments',
        headers={
            'Content-Type': 'application/json',
            'X-API-Key': SYNC_API_KEY
        },
        json=payload
    )
    return response.json()

@app.route('/webhooks/syncpay', methods=['POST'])
def handle_syncpay_webhook():
    """Processa webhooks de confirmacao de pagamento."""
    payload = request.get_json()
    
    # Verificar tipo de evento
    if payload.get('event') != 'payment.confirmed':
        return jsonify({'status': 'ignored'}), 200
    
    data = payload.get('data', {})
    
    # Extrair dados relevantes
    payment_id = data.get('id')
    course_id = data.get('metadata', {}).get('course_id')
    student_email = data.get('customer', {}).get('email')
    student_name = data.get('customer', {}).get('name')
    
    # Aqui voce implementa a logica de negocio:
    # - Marcar pedido como pago
    # - Criar conta no LMS
    # - Enviar e-mail de boas-vindas
    print(f'Pagamento confirmado: {payment_id}')
    print(f'Liberando acesso ao curso {course_id} para {student_name} ({student_email})')
    
    return jsonify({'status': 'processed'}), 200

if __name__ == '__main__':
    app.run(port=5000)
```

```javascript JavaScript (Express)
const express = require('express');
const axios = require('axios');

const app = express();
app.use(express.json());

const SYNC_API_KEY = process.env.SYNC_API_KEY;
const SYNC_BASE_URL = 'https://api.syncpay.com.br';

// Criar cobranca PIX
async function createPixPayment(amount, description, customer, callbackUrl, metadata) {
  const response = await axios.post(
    `${SYNC_BASE_URL}/v1/payments`,
    {
      amount,
      currency: 'BRL',
      description,
      expires_in: 3600,
      customer,
      callback_url: callbackUrl,
      metadata
    },
    {
      headers: {
        'Content-Type': 'application/json',
        'X-API-Key': SYNC_API_KEY
      }
    }
  );
  return response.data;
}

// Webhook handler
app.post('/webhooks/syncpay', (req, res) => {
  const payload = req.body;
  
  if (payload.event !== 'payment.confirmed') {
    return res.json({ status: 'ignored' });
  }
  
  const { id, metadata, customer } = payload.data;
  
  // Logica de negocio: liberar acesso, enviar e-mail, etc.
  console.log(`Pagamento confirmado: ${id}`);
  console.log(`Liberando curso ${metadata.course_id} para ${customer.email}`);
  
  res.json({ status: 'processed' });
});

app.listen(5000, () => console.log('Webhook server running on port 5000'));
```
